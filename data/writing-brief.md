# 写稿简报（所有出稿任务必读）

自检口径以 `scripts/audit_ready.py` 为准，五维满分 100，**≥85 才算达标**，低于 85 的稿不进发布池。

## 一、四形态硬指标

| 形态 | id | 中文字数 | 配图 | 小标题 | 段落 | 列表/引用 | 首段 |
|---|---|---|---|---|---|---|---|
| 公众号文章 | `gzh-article` | 1400–1650 | 5–6 | 4–6 个 | ≥8 | 至少 1 个 list | ≤120 字，带时间锚+数字 |
| 公众号贴图 | `gzh-poster` | 380–560 | 6–9 | 不用 | 3–8 | 可选 | ≤90 字，每段 ≤220 字 |
| 头条文章 | `tt-article` | 1150–1400 | 1 | ≥4 个 | ≥8 | 至少 1 个 list | ≤90 字，带时间锚 |
| 微头条 | `tt-micro` | 300–390 | 1 | 不用 | ≥3 | 可选 | ≤90 字，带时间锚+具体数字 |

字数**只计中文汉字**（`[\u4e00-\u9fff]`），标点、英文、数字不计。写 1500 汉字 ≈ 实际文档 1700–1800 字符。

## 二、标题（15 分）

- 12–32 个汉字；带**数字**或**疑问**（二选一，各 5 分）；
- 必须含一个转折/悬念词：`但 / 却 / 其实 / 原来 / 前提 / 真相 / 别急 / 先 / ？`（4 分）；
- 不许夸大、不许伪造数字、不许「震惊体」。

## 三、开头钩子（15 分）

- 首段 ≤120 字（≤90 字最稳），必须是**具体事实**，不是议论；
- 首段要有数字/日期/机构名锚点；
- 首段必须含时间锚：`这两天 / 今天 / 刚刚 / 最近 / 上周 / 昨天`，写「11 月 23 日」不算时间锚，要配一个口语时间词。

## 四、结构（20 分）

- 长文（公众号/头条文章）：小标题 ≥3（≥4 更喜欢）、段落 ≥8、至少一个 `list` 或 `quote`；
- 贴图：配图 ≥6 拿满分（3–5 只给一半）、段落 3–8、平均每段 ≤220 字；
- 微头条：段落 ≥3、首段 ≤90 字、有配图。

## 五、文件与字段

一个选题一个文件：`data/ready/YYYY-MM-DD-<slug>.json`

```json
{
  "version": 2,
  "date": "2026-11-24",
  "slug": "kebab-case-英文短名",
  "sourceItemId": "情报条目的 id",
  "sourceTitle": "原情报标题",
  "sourceUrl": "原链接",
  "sourcePlatform": "微信公众号 / 今日头条 / 知乎 …",
  "verification": "已核实 / 部分核实 / 待核实",
  "verificationNote": "还缺什么证据（如实写）",
  "imageNote": "",
  "batch": "morning",
  "pieces": [
    {
      "id": "gzh-article",
      "target": "公众号",
      "form": "文章",
      "badge": "6 字以内的栏目词",
      "title": "标题",
      "digest": "60–90 字摘要",
      "images": [],
      "blocks": [
        {"type": "para", "text": "..."},
        {"type": "h2", "text": "一、小标题"},
        {"type": "list", "items": ["...", "..."]},
        {"type": "quote", "text": "..."}
      ]
    }
  ]
}
```

- `pieces` **只放一篇**（一条情报只出一个形态，绝不派生多形态）。
- `images` 一律留空数组：配图由 `scripts/rebind_images.py` 按「原文图 > 豆包 > ChatGPT > 自制卡」统一绑定，写稿时不要自己编图片路径。

## 六、事实纪律（红线）

- 事实只能来自该条情报的 `summary` / `verification` / `citations` / 原文页面；
- 不许编造数字、引语、检测结论、机构表态、网友评论；
- 核实状态照抄情报条目；未核实的，正文写明「尚未得到官方确认」「目前只有当事方说法」；
- 拿不到的数据写「不可见」，不估算、不猜；
- 不写诊疗建议、投资建议、法律个案结论；不写政治敏感内容；
- 不登录、不代发任何平台。

## 七、常见扣分点（历史踩坑）

1. 字数不足：1500 汉字要求实际写 10–12 段，别按 800 字交差。
2. 首段没有时间锚 → 钩子丢 4 分。写「这两天，11 月 22 日……」。
3. 长文没有 `list` 块 → 结构丢 5 分。把并列事实写成列表。
4. 标题只有陈述句 → 标题丢 5 分。加数字或改成疑问句。
5. 贴图配图 6 张才满分，常见只配 4 张。
6. 同一事件写成多个形态 → `audit_ready.py` 判重复，整批被打回。
