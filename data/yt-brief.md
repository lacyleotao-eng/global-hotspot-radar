# 视频拆解稿 · 生产规范（唯一真源）

> 适用：`data/yt-digest/` 下所有「YouTube 长视频 → 一步步攻略」的稿子。
> 站点入口：首页「视频拆解线 · 视频攻略」。每天至少 3 篇，类型不重复。

---

## 一、选题：从哪类视频里挑

类型库（每天挑 3 类，同一天不重复；一周内不重复同一类，除非当天没有更好的片子）：

| Key | 类型 | 典型看点 |
|---|---|---|
| food | 美食探店 / 做饭 | 人均、必点、排队时间、怎么点最划算 |
| travel | 城市攻略 / 旅行 | 路线、交通、门票、几点去、住哪 |
| money | 赚钱 / 副业 / 生意 | 启动成本、获客、单价、真实流水 |
| invest | 理财 / 投资常识 | 规则、费用、风险点（不做个股建议） |
| work | 职场 / 效率 / 管理 | 具体动作、话术、工具组合 |
| tech | AI / 科技工具 | 能干什么、怎么配、坑在哪 |
| gadget | 数码测评 / 选购 | 参数取舍、价格区间、适用人群 |
| life | 人生感悟 / 情感 / 关系 | 只取可操作的部分，不写鸡汤 |
| health | 健康 / 健身 / 减脂 | 动作、频率、饮食、常见错误 |
| home | 家居改造 / 收纳 / 装修 | 预算、尺寸、施工顺序 |
| parenting | 亲子 / 教育 | 年龄分段做法，不贩卖焦虑 |
| study | 语言 / 考试 / 学习方法 | 每日安排、材料、避坑 |
| diy | 手工 / 维修 / 改造 | 工具清单、步骤、安全 |
| car | 汽车 / 用车 | 选购、保养、路况 |
| outdoor | 户外 / 露营 / 钓鱼 | 装备、点位、季节 |
| pet | 宠物 | 喂养、训练、就医 |
| fashion | 穿搭 / 美妆 | 场合、预算、单品 |
| create | 摄影 / 剪辑 / 创作 | 参数、流程、软件 |
| film | 影视 / 纪录片解读 | 只做信息型拆解，不搬运剧情 |
| law | 法律 / 办事 / 避坑常识 | 流程、材料、时限（不做个案建议） |

选片硬条件（缺一不选）：

1. 时长 **6–40 分钟**（太短没信息，太长一篇写不完）；
2. 有字幕：人工字幕优先，自动字幕可用；**完全没有字幕的不做**；
3. 信息密度够：片子里有具体价格、地址、时长、参数、步骤、材料之一，且能数出至少 5 个可执行动作；
4. 热度门槛：播放 ≥ 1 万，或发布 ≤ 14 天且明显在涨；老片只要能查到高播放也可；
5. 合规：不碰政治敏感、医疗诊断、个股荐股、违法操作；探店类不写"最正宗"这类绝对化结论。

## 二、事实纪律（比文采重要）

- **只写字幕里出现过的事实**。字幕没说的，一律写「视频里没说」，不补、不猜、不用常识填空。
- 每个关键数字/结论后面挂 `<span class="ts">00:12:13</span>`，时间戳必须能在原片对上。
- 口头夸张（"三千块""全广州最好"）不当作事实依据；要么不写，要么在文末「未采信」里点名。
- 有争议的说法单开一节，写清楚"视频里怎么说 / 可查的是什么 / 本文不下结论"。
- 平台/商家信息（地址、电话、营业时间）只写视频画面或字幕里出现的；没有就不写。

## 三、结构（照这个骨架写，步数 7–10）

```
<h1>标题：把最有用的那个数字/结论放进标题</h1>
导语：谁、花了多久、走完/做完什么，读者能得到什么（2–3 句）
<header> 素材：频道 · 时长 · 发布日 · 播放

0 先看结论：值不值得做 / 去         ← 3–4 个 KPI 卡片 + 适合谁 / 不适合谁
1 怎么开始：交通 / 准备 / 材料       ← 步骤化，能照着做
2 关键决策点：几点到 / 买哪个 / 怎么配 ← 表格对比
3..N 每一步怎么做                    ← 一节能写完的不要拆两节
N-2 避坑清单                         ← 表格：坑 / 怎么避
N-1 有争议的说法（有才写）
N  一页速查                          ← 无序列表，打印出来能带走
footer 事实来源 + 未采信 + 配图说明
```

写作口径：

- 第二人称 + 祈使句（"8:20 到门口"），不写"我们可以看到"。
- 一段不超过 4 行；能用表格就不写长段落。
- 标题 18–28 字，含一个具体数字；不用"震惊""必看"。
- 每节开头一句结论，再展开理由。

## 四、配图铁律（用户明确定过，违反即返工）

**允许的来源，只有两种：**

1. **原片截帧**（首选）：从播放器里取 1920×1080 原生帧，压缩成 1000–1200px 宽的 jpg。
2. **AI 生成示意图**：豆包 / ChatGPT 生成，图注必须写「AI 生成示意图（非现场）」。

**绝对禁止（一切"博主视角"素材）：**

- 博主本人出镜、正脸、半身、合影；
- 自拍视角、手持相机/手机的第一人称画面；
- 画面里有博主的手、手指、筷子夹持动作、举着菜单/物品的手；
- 路人/儿童的正脸特写（背影、远景人群可以）；
- 带频道水印、字幕条、播放器 UI 的画面（截帧前先确认没压字幕）。

**可以用的客观镜头：** 菜品、物件、工具、招牌、门面、街景、建筑、风景、信息牌、价目表、历史照片、地图。

数量与位置：

- 8–12 张；平均每 400–600 字一张，不要堆在开头；
- 首图放"这是哪儿/这是什么"，进正文前就让人有画面；
- 每张都必须有 `<figcaption>`：**画面说明 + `<span class="ts">视频截帧 00:12:13</span>`**；
- 封面用第一张（`meta.json.cover`）。

处理与体积：

- 宽度 1000–1200px，jpg q82–86，单张 < 250KB，整篇 < 2.5MB；
- 需要裁掉手/杂物时用 crop，不要用马赛克或模糊（会显得心虚）；
- 视频截帧不额外加滤镜、不加文字贴纸。

判定口诀：**这张图能不能换成别人在旁边拍的？能，就可以用；只有博主本人能拍到，就别用。**

## 七、已知坑（2026-11 实测）

- `yt-dlp` 直接下载视频会报 `Requested format is not available`（只剩 storyboard）：YouTube 对无 PO token 的客户端关掉了视频流。**改用 `scripts/yt_grab_frames.js` 在浏览器播放器里抽帧。**
- cookie 会被轮换，报 `Sign in to confirm you're not a bot` 就重跑 `scripts/yt_export_cookies.js`；需要 ego 里 YouTube 处于登录态。
- 纯暂停状态下 `currentTime` 赋值经常不落帧（静默停在 0 秒），抽帧脚本里必须"赋值 → 短播放 → 等帧"。
- 粤语等人工资讯轨在 `subtitles` 而不是 `automatic_captions`，`yt_transcript.py` 已经两种都试。
